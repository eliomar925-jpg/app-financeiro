# App Financeiro

Sistema web de planejamento financeiro familiar, com foco em controle de lançamentos, acompanhamento mensal, relatórios e organização da base financeira.

## Funcionalidades

- Painel financeiro com visão geral
- Planejamento mensal
- Alimentação mensal
- Relatórios
- Importação de lançamentos via planilha
- Exportação de dados
- Autenticação com Firebase
- Base de dados com Firestore
- Configurações da base financeira

## Tecnologias

- React
- Vite
- Firebase Auth
- Firestore
- Recharts
- XLSX

## Requisitos

- Node.js 18 ou superior
- npm
