Status

/api/health

Arquivos públicos: dados.json • fontes.json.

Séries adicionais • v2.0.1

IBGE: ipca_mensal, pib_anual_recente, pib_anual, pib_per_capita, pib_crescimento_anual, pib_4tri, rendimento, desemprego_trimestral e ocupados.

Para as séries diretas, historico=1 retorna os períodos publicados. Rendimento e desemprego_trimestral aceitam level=uf&id=29. Município retorna valor nulo e status nao_disponivel.

PIB anual recente soma somente os quatro trimestres de um ano completo (tabela 1846). PIB anual consolidado utiliza a tabela 6784; essas publicações têm referências diferentes.

BCB: divida, selic, cambio, reservas, primario_pib, juros_pib, nominal_pib, conta_corrente_pib, primario_rs, juros_rs, nominal_rs, dlsp_rs. Valores *_rs estão em R$ milhões. Fluxos mensais em R$ não se comparam diretamente a acumulados em 12 meses em % do PIB. Selic 4189 é mensal anualizada, base 252.

Respostas: 400 para parâmetros inválidos; 502 para fonte indisponível ou conteúdo inválido. Cache compartilhado com stale-while-revalidate. Data de consulta não substitui período de referência.
